# White-box Testing Practice - Java

## Mục tiêu
Thực hiện 8 bài toán nhỏ bằng Java, viết test JUnit để đạt coverage cao (ưu tiên 100% statement và branch).

## Cấu trúc
- `src/main/java/com/hieu/math` chứa mã nguồn.
- `src/test/java/com/hieu/math` chứa test JUnit.
- `pom.xml` cấu hình Maven và JUnit 5.

## Cách build và chạy test
1. Cài Maven và JDK 11+
2. Từ thư mục gốc project:
   mvn test
