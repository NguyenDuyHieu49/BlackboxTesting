# BlackboxTesting

## Nội dung

Bài thực hành kiểm thử hộp đen gồm:

1. Chu vi hình chữ nhật
2. Diện tích hình chữ nhật
3. Giải phương trình bậc 2
4. Số ngày trong tháng
5. Kiểm tra số nguyên tố
6. Tổng S
7. UCLN
8. Tổng giai thừa

## Kiểm thử hộp đen

Áp dụng:

- Phân lớp tương đương
- Giá trị biên
- Dữ liệu hợp lệ
- Dữ liệu không hợp lệ

## Cấu trúc repo

src : code chương trình

testcases : test case

result : kết quả chạy

## Cách chạy

g++ filename.cpp

./a.out
