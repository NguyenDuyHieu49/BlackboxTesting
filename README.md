# BLACK BOX TESTING PROJECT

## 1. Giới thiệu

Dự án này thực hiện kiểm thử hộp đen (Black Box Testing) cho 8 chương trình lập trình cơ bản bằng ngôn ngữ C++.  
Mục tiêu của dự án là thiết kế test case, thực hiện kiểm thử và ghi nhận kết quả kiểm thử theo yêu cầu của bài tập.

---

## 2. Nội dung thực hiện

Dự án gồm 8 bài toán:

1. Tính chu vi hình chữ nhật  
2. Tính diện tích hình chữ nhật  
3. Giải phương trình bậc 2  
4. Tính số ngày trong tháng  
5. Kiểm tra số nguyên tố  
6. Tính tổng S = 1 - 2 + 3 - 4 + ... + n  
7. Tìm UCLN của hai số  
8. Tính tổng S = 1! + 2! + ... + n!  

---

## 3. Phương pháp kiểm thử

Dự án sử dụng phương pháp kiểm thử hộp đen bao gồm:

- Phân lớp tương đương  
- Giá trị biên  
- Dữ liệu hợp lệ  
- Dữ liệu không hợp lệ  
- Dữ liệu ngoại lệ
